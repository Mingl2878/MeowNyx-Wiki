# 特性威力默认值：纯注册表审计

## 接口与事件契约

浏览器 `window.TraitPowerDefaults.resolve(pet, skillName, skillAttr)`；CommonJS `require("../js/trait-power-defaults.js").resolve(...)`。仅返回 `null` 或 `{field, value, mode, reason}`；没有伤害集成、DOM、存储或服务调用。

- `fixedBonus`＝固定威力；`percentBonus`＝百分比威力，均不是攻防BUFF。
- `default`：仅每次选择攻击精灵时应用，覆盖仅该字段；技能改变不得覆盖之后的临时人工调整。
- `dynamic`：选择攻击精灵、技能名或属性变化时重算；明确不满足返回value 0，仅关闭该字段。
- `null`：保留手动值，不得转换成0。未知属性也不能当成非光系/非本系。
- 稳定ID决定身份，中文名称只用于编写此审计；运行时校验完整特性名与描述快照，源更新不匹配即安全返回null。无按精灵名或宽泛正则推断。
- 同家族仅枚举下列实际ID，不自动扩大到未审阅新形态。不模拟技能赋予的全技能/两侧加威力，不把攻击增益、减伤或反伤当默认威力。

## 源特性快照

- **顺风**：若先于敌方攻击，本次技能威力+50%。
- **破空**：若先于敌方攻击，本次技能威力+75%。
- **挺起胸脯**：携带的能耗为1的技能，威力+50%。
- **“国王”的威严**：鸭吉吉国王的种族资质大幅增加，能耗为1的技能威力+50%。
- **勇敢**：携带的能耗大于3的技能，威力+40%。
- **不移**：携带的无额外效果的攻击技能，威力+30%。
- **水翼飞升**：己方精灵每使用1次水系技能，自己入场时获得全技能能耗-1，且能耗为0的技能威力+30%。
- **电流刺激**：携带的攻击技能获得迸发：威力+40。
- **向心力**：1号和2号位技能获得传动1和威力+30。
- **绒粉星光**：攻击时，若敌方血脉是非本系的系别血脉，技能威力+100%。
- **月光审判**：攻击时，若敌方血脉是首领血脉，技能威力+100%。
- **冰雪魂魄**：天气为暴风雪时，冰系技能威力+100%。
- **目空**：携带的非光系技能，威力+25%。
- **夺目**：额外获得三个未携带的随机技能，且非光系技能威力+25%。
- **共鸣**：携带的「虫鸣」技能威力+20。
- **齐鸣**：自己携带的「虫鸣」技能威力+20，己方精灵携带的虫系技能获得巧变：虫鸣。
- **涂鸦**：使用非本系技能时威力+50%。
- **热成像**：若上回合双方有精灵使用火系技能，本回合自己携带的虫系技能威力+100%
- **冷光源**：若上回合双方有精灵使用翼系技能，本回合自己携带的冰系技能威力+100%
- **换碟**：自己携带的音波弹/音爆/金属噪音/午夜噪音威力提升，且获得巧变：同系别技能。

## 明确动态规则

- 小独角兽210、白金独角兽211、彩虹独角兽212：已知非光系25%，光系0。
- 共鸣/齐鸣213—220：只有技能名称虫鸣固定20，其余名称0，不扩大到全部虫系技能。
- 墨鱿士428、混乱鱿彩429：技能属于任一主副属性为0，已知非本系50%。
- 圣凯布米龙603、热团团607、焰米龙608：虫系100%，其他属性0，默认假定上回合条件成立。
- 猴麦仔509、音碟吼510：音波弹15、音爆20、金属噪音20、午夜噪音5固定威力，其余0。数值来自用户指示；原换碟正文未提供具体值。

### 月使鸷纳明确覆盖

仅ID604：用户明确要求**翼系**100%，非翼系0。当前冷光源资料实际写的是上回合翼系触发、本回合**冰系**加成；此为已批准的计算默认覆盖，不改源资料。未得到同等指示的月辉鸠606、新月鸷615返回null，不因特性相同自动跟随。604仍校验当前源快照，未来描述再次更新需重新审阅，不无条件套规则。
