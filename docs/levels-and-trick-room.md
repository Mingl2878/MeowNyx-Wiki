# 开发检查版：等级公式与霞光梦境

本轮为本地开发改动，未修改版本号、GitHub或已经生成的1.3 Setup/Portable发布包。

## 个体值与公式A

界面“+10”为简化档位，实际有效个体值为60；本软件只模拟未选0、满个体60。属性括号内加有效个体值/2，所以仍为0/30；不可再乘6。

设Q为对应资质，E为有效个体值0/60，N为性格倍率1/1.2/0.9，R为四舍五入：

- 生命：`R((R((L/50+0.5)*(Q+E/2))+L+10)*N)+100`
- 其他五维：`R((R((L/100+0.5)*(Q+E/2))+10)*N)+50`

等级系数先写为整数分子再参与计算，避免例如1.19×150被二进制浮点算成178.499999而错误舍入。旧有60级精灵的资质、个体开/关和三种性格组合与此前实现逐项对照；不能为了引入新等级改变这些属性基准。

## 公式B及取整

`C(L)=(10+0.45L)/41=(1000+45L)/4100`，使用攻击方等级。

每击伤害仅在最终结果向下取整；过程中不再逐步ceil。连击仍为每击结果乘连击数，星陨作为独立追加伤害，仅最终floor，再与普通伤害相加。实际计算使用完整等级系数，不使用显示舍入值。普通精灵仍显示0.9；可调等级精灵显示两位小数，例如Lv99显示1.33，Lv60显示0.90。

技能基础/最终威力等非伤害整数结果采用四舍五入。扇风75×1.5改为113；150×1.25×3改为563，不再562。只改游戏数值，不能机械替换画布坐标、刻度上界、数组索引或二分搜索的取整。

普通伤害参数为 `normalDamage(attack,power,defense,reduction,combo,level,effectiveness)`；后置属性倍率也必须放进唯一的最终floor之前。星陨使用同一攻击方等级。

攻守双方分别提供不可点击的 `lv：等级` 文字、滑块及 `<` / `>` 相邻档位按钮，替代本侧资质/属性值切换，始终显示属性值。普通精灵仍为60级并恢复原切换控件。

滑块档位为1、9、19、29、39、49、59、69、79、89、99。旧手动编辑弹窗已删除；已有有效手动等级读取时保留，用户主动拖动或增减后以新的档位为准，不被旧覆盖锁住。步进按钮按当前实际等级寻找相邻档位，旧43级减/增为39/49；边界禁用。全部新界面样式由CSS类提供，完整交互见[更新审阅与等级控件](<update-review-and-level-ui.md>)。

`rk_damage_levels[speciesId]`分别保存`attacker`和`defender`的`{slider,manual}`，独立于个体/性格、技能记忆和编队。失败仍有可见队列与重试、关闭flush。普通精灵不读取特殊等级。其他页面通常不带入伤害页等级覆盖，冥古龙按资料默认99；2026-11-01伤害曲线攻击方改为读取卡片有效等级，防守/收藏仍按资料默认等级（详见下节）；速度速查另有明确特例，只显示一条固定身份的专用行，初始`70 · Lv99`，固定放在105与100档位之间、不随等级移动，文字右边的`<`、`>`按完整1、9、19、29、39、49、59、69、79、89、99档位降/升，边界禁用。所有速度列、加成和比较结果实时按当前等级重算，保留已选列、行/按钮DOM及键盘焦点；不重复添加精灵，也不并入普通60级行。当前等级仅速度页会话内保留，搜索/切页不重置，重启回99，不读写伤害页等级或个人配置。

## 通用等级与狼王菜单（2026-10-30增量）

特性名称或描述包含“等级”时，伤害卡片自动显示等级控件；用户也可在“数据更新→编辑精灵”手动开启。默认等级、最低/最高等级和整数步进均可配置，分别使用canonical的`default_level`、`level_min`、`level_max`、`level_step`；默认等级必须在1—99内的滑块范围中。以默认等级为步进基准，保留范围两端，因此两端允许不足一个步进的间隔。没有明确设置的普通自动控件默认60级、1—99、步进1。旧有效等级记忆不能越过配置范围；主动操作后使用新档位，不再提供点击等级手输。未编辑这组字段时编辑页保存不回传，以免旧表单擦除设置。新来源尚未确认应用时，不提前改变当前控件。

银月狼王595及明确进化链诅咒狼灵616、新月狼灵617，攻守卡片改为自定义CSS按钮/浮层的四选一下拉菜单（非原生select）：

| 模式 | 等级规则 |
|---|---|
| 属性值 | 60级，显示属性值 |
| 种族值 | 60级，显示种族值 |
| 冥古龙 | 每次切入重置99级，滑块1、9、19、29、39、49、59、69、79、89、99 |
| 阿布 | 切入默认60级，滑块60、62、64、66、68、70、72、74、76、78、80、82、84、86、88、90、92、94、96、98、99 |

模拟始终使用原狼王链精灵的资质/属性/技能和正式特性资料，不切换所选精灵。2026-11-01用户明确要求三只狼系共享下节所列的阿布物攻成长及阿布/冥古龙低等级受击效果；除这些明确规则外不猜测其他机制。狼王模式和等级只存会话，按精灵ID与攻守侧独立；不写个人/编队/技能以及普通等级记忆。战报临时快照优先，进入快照时隐藏狼王菜单。冥古龙本身的已有等级记忆不重置、不排查或迁移。

实现策略位于[等级策略](<../js/pet-levels.js>)，通用等级编辑通过现有revision保护的图鉴事务保存。除伤害曲线攻击方的下述特例外，其他页面仍使用精灵资料默认等级，不读取狼王菜单或伤害页个人等级覆盖。

## 超能阿布与狼系模式效果（2026-11-01）

独立精灵超能阿布623：单龙属性8、首领形态，生命126/物攻122/物防80/魔攻45/魔防100/速度105。特性“圣龙的守护”原文为“己方精灵每使用1次能耗为3的技能，自己入场前等级+2。在战斗中每提升1级，获得物攻+5%，低于80级时受到伤害+30%。”。独立own学习面只有现有龙吼244（1费、物攻60威力）和龙炮245（3费、物攻100威力），不新增或修改主技能。图鉴编号为待补0、图片为空、对应普通形态未知；不造普通阿布或关联狼王，保留独立首领记录。

- 本体默认60级、范围60—99、步进2（含末端99），沿用通用滑块和相邻档位按钮。攻守等级分别记忆；狼系595/616/617仍使用原会话模式/等级，不写入资料或个人等级。
- 本体或三只狼系阿布模式作为攻击方时，物攻技能额外增益为`max(0, 当前攻击方等级-60)×5%`，写在**增减益buff**而非威力百分比中。零手工基准时60/62/80/99级分别显示0/10/100/195；与独立手工BUFF相加，不乘方、不累加重复渲染。切魔攻技能只撤此物攻分量，保留手工BUFF；切回物攻按当前等级恢复，手工接管除外。
- 手工输入合法BUFF（包括负数和空白0）接管字面值并暂停自动成长，不反算成“手工值减旧成长”；普通计算/切技能不解除接管，下一次明确调整攻击方等级或模式才恢复自动。原生623接管标记仅保存为`rk_damage_skill_configs['623'].abuBuffOverridden`非null布尔，狼系标记只存会话；无归属的活动技能快照绝不携带该标记。保存的BUFF只包含手工部分，不能烘焙等级增益或污染其他精灵。
- 受击方本体623，或三只狼系的阿布模式，等级严格低于80时自动填**威力百分比加成30**；三只狼系冥古龙模式低于80时填40，原生冥古龙619的40规则保持。条件只看受击方，攻击方阿布成长与受击方加成可以独立同时生效。
- 达到80或离开条件时撤销对应临时30/40，恢复手工值或已确认攻击方特性默认值，不与原值相加，不把临时值写成永久技能设置。狼系退出阿布模式只撤其自动物攻分量；原机幕方舟、烈火战神吹火、手动最终威力及非法草稿保护保留。
- 等级用于当前试算，不自动统计全队3能耗技能、回合或累计成长事件。战报试算使用临时有效等级，不能把个人狼系模式当作快照；临时调整不写个人/编队，退出恢复进入前值、自动分量和接管状态。
- 资料由开发命令[abudata](<../cmd/abudata/main.go>)离线追加三条记录（精灵、特性、学习面）。默认仅审计；源文件或本地不可变store提交须明确路径、准确revision、项目外备份，本地提交还须关闭应用。冲突/部分安装拒绝，不清其他精灵、来源基线、策略和身份预约；不是启动迁移。

## 曲线攻击方等级与展开公式（2026-11-01修复）

伤害曲线读取`DamagePage.CalcEngine.effectiveLevel('attacker')`，而不是把攻击方固定在资料默认等级。原生等级控件、狼系阿布/冥古龙模式、临时战报等级均通过同一来源带入；防守资质曲线、攻击资质扫描、威力扫描、收藏头像的真实伤害/参考伤害/斩杀门槛与动态预设保持一致。

- 攻击个体/性格仍由曲线自己决定，用原资质与当前等级重算，不复制伤害卡片的已算属性。普通精灵的临时快照等级也须参与，不能通过会忽略普通精灵等级覆盖的通用属性接口退回60。
- ①展示`R((R((L/100+0.5)×(Q+E/2))+10)×N)+50`，带入实际L、资质Q、曲线个体0/60、性格1/1.2，并标注R为四舍五入；扫描模式使用其当前试算资质，不错拿原精灵资质。
- ⑤展示精确`(1000+45L)/4100`，逐击最后向下取整后再乘连击；不再只显示0.9或两位近似系数。单线仍为①—⑥，多线仍只列各可见线⑥，不增加第七步。
- 本次只带入攻击方有效等级。防守/收藏生命与防御继续各自资料默认等级，防守参考曲线仍用选中受击精灵默认等级；不读伤害页个体/性格、不写新的曲线等级配置、不改变ALL/隐藏曲线状态。原有BUFF、百分比、连击和各模式排除项保持，阿布成长不重复加算。

## 曲线取整边界

后续曲线四按钮、固定生命个体、单线红绿框和动态不可斩杀预设见 `chart-survival-groups.md`；相关控件旧约定以新文档为准。

曲线保留原有计算效果取舍，不引入原先排除的减伤/星陨/手动最终威力。实际伤害采用最终floor和目标真实等级。

等效生命显示改为`HP/属性倍率`的中性未取整参考，不再沿用旧ceil模型的`floor((HP-1)/倍率)+1`。这是辅助坐标，不能用采样曲线像素或已经floor的中性伤害再乘倍率来判断精确生存；实际伤害、剩余生命、能否扛住由完整计算给出。免疫不画无穷点，攻击资质/威力击杀点继续用实际公式进行整数搜索。

## 霞光梦境（原名戏法空间）

设置的速度计入选项旁有“霞光梦境”复选框，默认关闭；已有开关状态保留，内部trick_room配置名不变。它与其他设置一样先改草稿，成功保存后才更新运行状态和缓存。

仅精灵图鉴视图将速度资质投影为`200-原速度资质`，据此重算总资质、有效种族值及相关排序/排名；速度综合门槛也使用投影后的速度。不修改主数据或全局基础属性接口；其他页面、伤害计算、曲线、编队、技能学习者表均不受影响。关闭后恢复原值。

例：音速犬速度120→80，总资质542→502；包含速度时有效种族值504→464；不包含速度时保持384；速度综合门槛80时变为464。

后续的技能累计、特性默认值、速度历史排序和属性关系工具见 `skill-simulation-and-type-tools.md`，其中鸣沙/闪击威力档位已更新。
