# 成长、赛季筛选、进化链规则与条件反推（2026-11-02晚间）

本节覆盖旧的初始技能携带显示、敌方技能发生率、精确终阶规则和非速度全个体枚举统计约定。所有统计仍共用一次筛选后的记录和同一份不可变图鉴快照；不向原始战报回写派生结果。

## 成长有效样本

双方表现第五列，自行离场之后、已有过山车率之前，新增 `场均特性触发` 与 `技能名叠层数`。每个指标单独统计有效样本：确认零计0，缺失不进入分母。不能用未选技能、个人模拟累计、`grow_times` 或所有施放次数填空。

选定特性共22项：爆燃、三鼓作气、蓄电池、洄游、合拍、光度换算、水翼推进、水翼飞升、身经百练、渗透、拨浪鼓、蒸汽膨胀、定向精炼、搜刮、扫荡、淬炼火、猫精灵的礼物、旧玩具、蒸汽革命、圣龙的守护、花精灵、坚韧铠甲。按稳定特性ID与主资料的原生持有者匹配；花精灵包括小草虫/草衣虫/花衣蝶，坚韧铠甲包括小甲虫/铠甲虫。其他未选特性不添加。

选定技能共16项：光能聚集88、吹火113、流星火雨126、山火131、水波术154、过曝173、绵里藏针252、落雷272、齿轮扭矩429、友谊满溢510、远行537、孢子爆散79、趁火打劫404、试飞538、感电265、水刃163。

- `stats.growth.me/enemy` 按初始物种归集；`trait` 和 `skills[]` 各含 total/samples/unknown/average，average无有效分母为null。
- 特性计触发，不按双攻/双防多个通知重复计数。技能有 `unit` 说明：固定威力按对应成长档换算（吹火+20为1层），新增连击按1连击/层（孢子+2为2层），降费按1能耗/层（水刃-3为3层）；山火为明确翻倍次数，不能从倍率猜次数。试飞分power/hits两路，感电是技能使用次数参数，不是已施放次数。
- 新可选 `event.growth`：traitId、branch、occurrenceId、mode(delta/total)、complete。Stacks是明确层数；Amount只在单位确定时换算。complete说明该效果的整场覆盖，不等于某次动作完整；total必须是本局累计新增量，不是当前残留或初始值。
- 同一occurrenceId合并双属性通知；冲突、部分累计下界大于完整增量等情况不可认证为已知。源形态在同帧缺少执行顺序时保持未知，不用数组顺序或缺失序号=0来猜。
- 完整动作可推导的路径仅限已审核且能确认生效的简单使用/属性使用/入场条件。复杂历史、应对、选择、槽位、封顶、额外回合末触发等仍须实际效果证据。质量不完整不会升级；没有完整证据时不是0。

## 通用规则、默认分类与编辑

每个正向核心、排除成员和 `anyOf` 组，均沿图鉴明确的普通前置与首领关系匹配完整家族。不使用名字、同图鉴编号、成员数组邻近或main_form_id把无关/地区分支混起来。anyOf组内任一满足，多个组之间全满足；和monsterIds必含、excludedMonsterIds排除共同生效。同一家族重复条件属于集合谓词，不隐含要求多个实例。

星光/卡瓦重地区分支的明确前置不同，因此星光规则不包含月光，狼王中的卡瓦重仅雪山/火山分支；恶魔狼/恶魔狼王不混入银月狼王一家。首领化或进化不改变同一实例的原始阵容归类。全部完整已知初始阵容按顺序仅归首条；无匹配为其他，不完整阵容不冒充其他。

随包并嵌入Go的 `data/default-battle-rules.json` 保存15条用户指定分类，顺序为雨天、雪天、星陨、毒队、萌队、虫队、地武、火队、雷暴、狼王、火神、高脚、三三、电鹿、罗隐。每条种子ID及形态经过当前主资料独立核验。

- 新用户/尚未配置且无规则时，GET返回内置默认，不插入默认rule rows。
- 已有自定义规则优先。成功PUT（包括[]）保存configured标记；明确清空后不会每次启动恢复默认。辅助状态表兼容原schema1。
- GET/PUT rules返回rules/revision/defaults。载入内置规则需二次确认，只替换草稿、不改变当前已应用配置；点击保存才提交。已有实际用户规则不被静默覆盖。
- 点击已有规则整行/头像/文字即可编辑原stable ID，保存不是重复新增。删除/排序控制不触发行编辑。新增自动暂存当前有效输入；保存自动应用当前输入。移除应用到草稿按钮和旧长说明。
- 保存仍需精确已加载baseRevision；冲突不盲目重基线或覆盖远端新增内容。载入默认也不能绕过冲突核对。
- 原初始化list/stats/rules并发超过后端2槽的问题改为客户端2并发队列，排队写操作立即加入关闭等待；排队GET可取消，活动传输结束前不释放槽。真实失败保持中文提示，不把失败伪装保存成功。

## 敌方体系组件的技能使用率

体系核心及其他队友单元格内一行一只。展开的 `技能使用率` = 该体系内该精灵的对应技能已确认执行次数 / 其纳入统计的总执行次数。允许部分动作记录，但仅表示已记录行为；多段一次、未执行不计、聚能排除、愿力按明确属性分项。同种精灵跨体系不混，交换后实际执行的技能可以计使用，但不冒充初始携带。

组件DTO为skillUsage[] + usageTotalCasts；旧InitialSkills输入证据仍可合法保存/合并，但不再用于这个界面。删除生命个体/性格联合分布面板；保留分项个体/性格。

## 条件配置反推

`PrepareBattleInference` 是纯视图投影，统计前在深拷贝记录上运行。表现/伤害估算与成长仍使用原记录，不让条件IV60进入原始伤害估算；原始事件、记录、个人配置均不回写。

- 非速度固定有效个体60（界面+10）作为假设，联合枚举性格0/1/2。仅条件可靠且joint singleton纳入该属性；无解、多解、缺条件只排除该属性样本，不删除对局。
- Condition=`effective_iv_60`及证据文字明确保留假设。分布按体系精确统计ivConditionalSamples/natureConditionalSamples，UI标注按+10前提；不声称匹配成功已证明实际个体60，也不声称失败证明没开个体。
- 原始直接值不覆盖，包括我方生命个体54。生命需要明确初始绝对HPMax/形态/等级。后续形态/生命上限变化不套初始条件。
- 四项伤害属性支持已有明确constraints，以及自动读取带核实damageFormula的实际单击HP伤害；需实际威力、物魔、双方当次形态/等级、攻防倍率、减伤、克制、无盾/回血混合证明。目录基础威力不能替代实际威力；HP0过量伤害不视为精确击中数值。
- 速度复用现有UI条件候选能力；后台数学推断仍保留同速的双向可能，不将连续两次先手启发式当成严格不等式或唯一证据，不强制IV60。
