# 1.3 检查版约定

## 版本及交付

- `version.txt` 是唯一版本号来源，当前1.3。Go窗口标题和Inno安装显示名使用“小黑猫 wiki 版本1.3”。运行文件名、用户数据目录及安装AppId保持兼容，不迁移或删除旧安装。
- 本轮只构建并同步 `dist/app` 检查版，不生成安装包/发布ZIP，不运行会清空dist的build.bat，不自动提交Git。

- 设置默认启动选项去除游戏描述，旧值回退图鉴；游戏描述页面和导航保留。

## 计算与数据

- 普通伤害及星陨共用精确系数37/41；界面约定显示0.9。
- 星陨仅由非幻系攻击触发，追加部分独立使用幻系对目标的克制。保持原攻击/防御属性取值、BUFF、减伤、防御修正；不叠本系、普通威力加成或连击。计算不会消耗模拟器的印记输入值。
- 星陨逐步取整：ceil(基础威力×攻击) → ceil(×37/41) → ceil(×BUFF) → ceil(×幻系倍率×减伤) → ceil(÷防御)。公式文案按倍率显示“幻系抵抗”（小于1）或“幻系克制”（大于1），等于1省略；仅显示文案不同，算法和取整不变。
- 双重克制3、单克制2、单抵抗0.5、双重抵抗0.25。
- 重击威力140、放晴能耗1；俯冲105保留。其他技能字段及学习面不变。

## 收藏及曲线

- 曲线收藏、分组及个体/性格独立，保存在共享配置 `rk_chart_workspace.state`；旧曲线收藏一次迁入“未分组”，不导入伤害页收藏或个人配置。伤害页收藏保持原样。
- 分组支持新建/重命名/排序/复制、移动成员、删除；删除组需确认，成员转未分组。跨组允许相同精灵，当前/全部组展示按精灵ID去重；用户暂不需要多配置头像，所有条目共用曲线控件。右键/Delete取消该精灵曲线收藏，不触碰伤害收藏。保存失败保留已提交界面，重试成功同步。
- 攻击精灵与技能参数仍可带入，但攻守个体/性格只来自曲线；默认攻击个体开/性格关、防御个体开、双生命关。切换伤害页个人配置不能重置曲线控件，曲线也不反向写个人或编队。
- 原比较功能保留，图例直接说明实际组合（+个体、✓性格、负性格、物防/魔防个体等），不再使用“当前配置”或模糊的对比名称。不同精灵同坐标时，头像视觉避让并用引线指向真实点；原始x/y不变。CSS缩放下悬停和右键命中必须统一转换成画布布局坐标。
- 超出横轴或无法击倒时，在列表下提示无可见标注的数量，完整原因/真实坐标保留在头像悬停提示，不用长文字撑大单个头像项。
- 伤害—防御模式：头像横轴为真实防御资质，纵轴改为按实际属性折算的等效生命。以真实ceil操作求最小整数中性伤害，不简单用HP/倍率；倍率1时权杖-V双生命仍为(136,455)。真实HP、实际伤害、剩余HP、生存情况另列；只可与相同攻防配置的参考曲线比较，配置与参考线不同时明确提示。采样插值不代替严格伤害判定。防御—伤害模式保留精确整数最低击杀攻击资质/威力，纵坐标仍为目标生命。
- 手动克制按钮和顶部“克制/抵抗×…”字段已删除，主线不再有隐藏倍率；每目标按实际属性计算。各模式原有的计算效果取舍不变，不因删说明纳入星陨/减伤等排除项。
- 纵轴实际网格间隔限定10/20/25/50，按范围及绘图区高度细化，超501刻度或无效数值明确暂停，不偷偷用更大间距。画布窗口化保留520上限、真正最大化按原生状态解除上限填充剩余高度，同时预留收藏区；收藏工具/头像居中，眼睛按钮仅切换图上标注。顶部冗长说明删除，配置差异/取整精度在悬停保留；图例用“攻：✓个体&×性格 / 防：✓个体&×性格”，负性格单列，启用符号统一✓。
- 数值横轴支持奇数位置；超出范围/搜索上限内不能击杀必须明确提示，不冒充边界点。头像缓存最多64张，更多标注保留圆点与完整提示，不删除收藏。
- 画布始终用容器未缩放内容尺寸显式resize；创建、resize、appzoomchange、重建均覆盖。离页清理observer、订阅和帧任务。

### 内置属性预设分组

管理分组旁有“预设分组”入口，血脉同款三行六列18属性图标（无无/首领行）。组名“所有xx系精灵”，成员取当前主资料中非隐藏、非首领的高级形态，形态分类为主形态或无多形态，主/副属性任一匹配；按稳定ID去重。内置组随资料更新派生，不能直接增删改名，不会混进普通分组的“全部分组”。可复制成普通组后自由编辑；不改曲线的共同个体/性格或伤害公式。

- 不提供正则搜索。公共精灵下拉候选不再截断为10条，可滚动选择完整结果，原业务过滤保留。
- 图鉴/技能列表已正式采用内嵌工具栏，专用回退方案已删除：搜索与右侧三态按钮常驻，只控制下方筛选条件；宽窗400px搜索居中，窄窗允许收缩但不得被按钮遮挡。移动原DOM而非重建，不丢条件/输入法/焦点；浮窗只包含条件、在工具栏下方；浮窗模式鼠标进入整块常驻筛选区（含搜索/空白/按钮）即打开，离开约80ms关闭；折叠模式不悬停展开，键盘只聚焦搜索不强制打开，键盘焦点仍可操作。实际:hover与指针/键盘来源分开，避免portal移动和鼠标点击焦点把浮窗卡住。各页独立记忆。
- 已修正主资料中阿米樱197、吸泥鸥436、焰米龙608的前序形态误标，仅将其evolution_stage改为基础形态；后续进化、首领身份、技能继承、数值和图片保持不变。不是在图鉴页面隐藏名称。
- 技能详情默认/表格使用学习者标题右侧的分段切换，不使用下拉菜单。默认保留来源分组；表格按ID去重、不展示来源列，数值表头排序稳定，交集结果同样适用。交集已选技能仅保留图标/名字，左键整块移除，不显示叉号和属性标志。
- 技能详情及交集表格的“属性”表头可打开三行六列的18属性选择器；主/副属性任一匹配置顶，不筛掉行、组内沿用数值排序，再点同属性取消，默认分组视图保持来源分组。不会修改精灵/血脉属性；新详情默认未置顶。
- ListingUI为两页共用列/单元格/排序入口。有效种族统一RKData.getEffectiveStats：生命+较高攻击+双防+可选速度；原排名池不改。
- 有效速度模式为include/exclude/threshold（包含速度／不包含速度／速度综合），门槛40–120、步长1、默认80。仅速度综合显示滑块；base_spd达到门槛则整项计入，否则该项不计，等于门槛计入。旧boolean字段兼容读取。草稿或保存失败不得改变实时值，成功后由AppPreferences提交并派发全局刷新。

## 队伍与速度

- 攻击汇总仅用当前队员携带且主技能表确认为物攻/魔攻的技能。每个目标属性、每只精灵最多计一次，任一克制招式优先记克制1，不再记抵抗；若没有克制但有抵抗，则抵抗1（普通攻击与抵抗并存的情况尚未获准改成最佳招式口径，保留原规则）。无攻击技能不计。
- 针对18个单属性分别计克制数、抵抗数；联攻净分=克制数−抵抗数，正数有利、负数风险，不等同最佳招式覆盖率。
- 速度列以真实可用宽度和32px头像+两侧1px边距计算容量，不固定7或13。保留搜索置顶和形态覆盖；窄窗口不压扁头像。
- 速度页当前勾选、固定/百分比加成、搜索、选中行列仅存内存，切页保留、重启初始，不再读取/迁入旧视图缓存。头像优先顺序、形态选择与统计门槛继续本地保存。

## 技能左右键

完整遍历579条主技能，不只用户举例。审阅注册表记录每条固定预设、普通攻击、需人工或非攻击的原因。固定左右分支分别设置单次基础威力与连击，不叠加点击次数；支持基础、血脉与过山车组。原历史/层数/能耗/队伍/关联技能等用户指定条目两键载入初始值；不自动模拟变量。四个不定威力技能仍显示“?”，点击时按用户给定左右数值填入；穿膛/背袭/色散按明确授权的威力快捷档处理。撕咬20威力、3/5连击，旧alt总威力150字段删除；其它主资料保持。

加尔与黑化加尔的选择攻击用固定加法表达式显示和记忆；求和后按单次释放，连击和星陨不重复，重复点击不累计。详见审阅表的专属映射。

成功点击技能不再在快捷卡片区域追加威力解释，输入/高亮/悬停说明仍保留，未应用与保存失败仍有必要提示。

技能档位与精灵0/1配置分开，完整技能快照仍保存。独立模拟修正保留，对机幕方舟真正换技能属性时继续已有25%/0关联覆盖。全量逐条清单及验证入口见 `skill-variants-audit.md`。

技能列表和精灵详情筛选支持左键纳入、右键排除、再次取消；按钮保留可见且显示排除标记，搜索和排序共同生效，不改队伍选择器默认交互。

## 共享个人配置

“全部精灵个人配置恢复默认”确认后锁内设mode0；新“清空所有精灵配置”确认后对当前全部精灵（含木桩）及已存个人记录设六个体false、六性格0、mode1，重启后仍不选择。两者不同，不通过删除记录触发自动默认。均先备份，不改技能、收藏、编队、曲线；不在软件更新时自动执行。指定的常驻解释文字已删除，确认对话框和保存保护仍在。

个人配置、选择、每精灵技能记忆及最后活动技能快照使用固定AppData共享文件。mode0生成自动默认，mode1保留人工配置，旧记录按人工保护。冷启动记忆攻击方和技能，不再兜底小黑猫或把已有威力归100；防守方冷启动固定木桩，切页不重置。浏览器缓存不是唯一来源；非破坏分组升级迁入、失败提示/重试、写前备份、原子替换和关闭时flush。具体接口、旧版本兼容边界及测试隔离见 `docs/shared-user-config.md`。
