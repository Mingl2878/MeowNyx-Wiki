# 更新审阅与等级控件（2026-10-30后续增量）

## 更新操作

“检查官方更新 / 确认并应用 / 重新载入资料”同排；冗余的初始操作说明和候选/记忆计数汇总已移除。阻断原因、失败、任务进度仍保留，不以精简界面掩盖未完成或错误。

批量操作仅修改当前预览草稿，不直接提交，也不对筛选结果或当前分页截断：

- **全选**：来源可用的候选选择来源；不可用来源不勉强选择。新选择默认不记忆。
- **反选**：已选行取消，未选且来源可用的行选择来源，不是本地/来源互换；取消行的记忆草稿同时取消。
- **取消选择**：清除所有本次选择和记忆草稿，不撤销已应用的业务值或持久策略。
- **记忆已选项**：仅给已选择本地/来源的行勾选“记忆此项”；不增加选择、不影响未选行，也不直接保存。

逐行长期策略文案由“以后也采用此侧”统一改为“记忆此项”。提交仍为原有 `acknowledge_only` 协议；只有确认应用成功才保存策略和资料。已保存记忆的管理操作保持独立。

## 长内容详情

长技能内容以“详情”入口展示，兼容独立学习面候选和完整新增精灵中的嵌套学习面。短字段和必要身份概览仍直接显示。CSS模态弹窗只读展示完整内容，不对其中的单个技能做子集选择，不额外请求来源，不截断真实资料；来源内容按文本插入，不执行HTML。

弹窗可关闭/Esc退出，限定高度并在正文内滚动。任务/候选失效或离页时清理弹窗，避免把过期内容当成当前预览；关闭恢复合理焦点。详情点击不改变来源/本地或记忆选择。

## 启动与来源边界

开机加载的是本地图鉴与个人配置，不自动请求腾讯图鉴，也没有新增定时更新检查。打开更新页面读取本机任务状态，不等于在线检查。明确点击“检查官方更新”才启动腾讯请求；加载、状态查询及详情查看不能替代用户确认。

此前启动性能修复通过精确不可变字节的本次进程缓存，减少重复的本地解析、校验和兼容投影；不是删除来源安全校验，也不是后台静默联网。

本轮不修改出厂业务资料、当前本地恢复测试结果或已有选择记忆，不重复删除或恢复三只方方系精灵，不清除个人数据。测试仅使用隔离内存或临时目录。
