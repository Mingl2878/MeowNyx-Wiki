## 属性关系页

进攻/防守各有独立的会话内选择，切换不清空。单选进攻属性时抵抗精灵只显示0.25倍率，标题为“x0.25倍 抵抗精灵（共N只）”；多选要求每个所选进攻属性倍率都<=0.5。

多选标题采用互斥汇总：有任意0.25倍率的精灵仅计入0.25组，其余全部0.5的精灵仅计入0.5组，每只只计一次。例如“抵抗精灵（共40只丨38只×0.5丨2只×0.25）”，采用丨分隔、数量在倍率之前；零数量分组省略。两/三/更多属性遵循同一规则，不把不同进攻属性的倍率相乘。

头像外圈按所选属性顺序等分，每个0.25倍率占红色一段、0.5不标红。全部0.25为整圈，混合两属性可为半圈，三属性可为1/3或2/3圈。仅改变外圈，不遮挡头像。标题/悬停/复制文本来自同一结果模型。

复制按钮左键复制当前模式的所选属性及关系分类，右键另附当前已有的抵抗精灵名单及逐属性倍率；防守模式没有精灵列表时不创造列表。支持键盘，成功只在按钮内短暂反馈，不显示旁边的成功说明文字，失败仍明确提示。复制不带精灵ID，倍率写成×0.5/×0.25等前缀形式，属性和倍率之间不加冒号，例如“白发路路；光×0.5；水×0.5；地×0.5”；复制标题与页面的互斥计数一致，不再附加“各进攻属性独立判断……”说明。数学规则保留；不安装全局右键或中键行为。

## 技能交互与持久化

悬停显示技能名、原始威力/连击和效果，不显示左右键操作说明。成功选择仍不添加技能区说明条。

`rk_skill_simulation['精灵ID:技能ID']`保存各技能自己的累计次数和输入值，切换/重启保留；主动左键才清当前技能的计数，自动恢复不能视为左键。

- 固定永久增威力：右键每次代表已触发一次，显示`基础+(次数*每次增加)`。
- 永久翻倍：显示`基础*2^(次数)`，^是乘方，不是JS异或。
- 永久连击：只增连击，不同时倍增单击威力。
- 手动改写基础威力退出相应自动累计，非法草稿不覆盖最后有效值。超出安全数值范围明确拒绝，不保存Infinity。
- 技能效果中给全技能、某类技能或两侧技能加威力的效果不自动模拟，攻击技能本身仍可使用。

魔能爆的输入框显示“当前能量”，左键10能量/右键0能量，允许手改0—10；对应威力为46、71、91、111、136、156、166、181、191、201、211。图标仍显示?。彗星输入“血量比”，默认100/100；每失去完整5%扣10威力，77/100为200。它不自动扣自身生命。

普通精灵的友谊满溢：左键70归零，右键永久+20并回普通档，中键对当前累计威力应用一次应对翻倍，重复中键不累乘。试飞：左键20威力/2连击归零，右键+10威力，中键+1连击，两类次数独立。加尔568/黑化加尔569的这两招保留原先明确的固定例外，不引入新累计/中键规则。

`skillInputKind`/`skillInputValue`与数值basePower和显示basePowerExpression分开保存；不能把能量6当成6威力。正常技能恢复基础威力输入标签。

## 烈火战神：吹火与爆燃累计

仅烈火战神（稳定ID14）右键吹火（技能113）触发这份新规则，要求爆燃特性和技能原文仍与审核内容匹配；排版空白不算机制变化。威力和BUFF以同一个累计次数n对应：基础50对应0%；50+(1*20)对应1×30%=30%；50+(2*20)对应2×30%=60%。每次右键使n增加1，BUFF按n×30，不再使用n−1，也不是连乘1.3。

- 双攻通过现有“增减益buff”进入物攻/魔攻的计算；不写技能的percentBonus、不改主资料资质、特性或技能原文。
- 切换其他技能，使用目标技能自己的威力，保留双攻累计；其他火系技能右键不增加此计数，其他精灵不应用。左键吹火同时归零吹火威力次数和双攻次数；左键其他技能不清双攻。
- rk_skill_simulation['14:113'].powerCount是共用的使用次数n（整数0—1000000）。每次显式选择吹火都会令fireAttackCount镜像该次n，旧未标记记录按powerCount恢复，修正两计数错位，不在启动时改写记录。手动改基础威力时以布尔firePowerDetached明确标记保留当时的fireAttackCount双攻分量；下一次显式吹火选择清除此标记并重新对齐n。
- 单独记录当前显示BUFF中派生的双攻分量，每精灵和活动技能快照只保存剩余手工分量。选回烈火战神或冷启动时从计数加回一次，避免重复相加；不对历史个人配置作启动写入或清空。
- 未手动接管时，例如独立BUFF20，基础50时显示20，第一次右键显示50，第二次显示80，第三次显示110；左键吹火归零后回到20。
- 在已有自动累计时显式手输BUFF，以输入值作为新基准并用fireBuffOverridden:true暂停旧派生BUFF，不保存成“输入值减旧累计”。累计60后切其他技手填0，再左键吹火保持0；主动输入-20则保持-20，不禁止负数。切技能/页面/精灵与重启保持此选择。下一次显式吹火选择清覆盖标记：左键清累计，直接右键则按当前powerCount+1重新计算自动部分；手工基准不被抹掉。
- 空白或纯空格BUFF按手动0处理，输入框可暂时空着，吹火左右键都必须可用。显式清空按0接管并保存；普通计算读取不写接管标记，但不能保留旧派生跟踪而反推负数。点击吹火时即使空白未先触发input事件，也先按手工基准0校验本次结果，校验成功才提交状态与计数。此空白兼容只用于BUFF，不放松通用表达式/威力解析器；非空未完成表达式（如1+）或溢出草稿仍不覆盖有效值与计数。保存继续走原失败重试/关闭等待。无法区分旧存负值是否用户主动输入，因此不做启动清理；如果已保存旧版产生的-60，需用户主动再设0一次。
- 战报试算另用会话计数，不把个人累计当作战报事实，不写个人/编队。进入时暂时移除个人派生BUFF，退出恢复进入前完整状态；重启不保留临时战报增长。

## 特性默认值与百分比记忆

明确的特性默认值在选中精灵时覆盖该字段的手动值；无默认/待确认的特性保留手动记忆，不因普通目标被强制清零。有条件按技能判断的规则，在换技能/改属性时更新自身负责的字段；不会每次计算都覆盖手工临时调整。

- 已确认固定默认包括岚鸟50%、神谕鲨30%、霜翼领主75%、鸭吉吉/国王50%、蒲公英娃娃40%、记忆石30%、星光狮固定40、声波缇塔固定30、绒仙子100%、疾光千兽100%、饮雪狂兽100%。这些是用户确认的初始试算，未自动推断先后手、能耗、天气或位置。
- 白金/彩虹独角兽非光25%否则0；风滚暮虫/暮风隐者仅虫鸣固定20否则0；混乱鱿彩非本系50%否则0。
- 圣凯布米龙虫系100%否则0；月使鸷纳（ID604）按用户指定翼系100%，冰系不生效（主资料原文仍为冰系，未改写）。
- 音碟吼：音波弹固定15、音爆20、金属噪音20、午夜噪音5，其余0。
- 布鲁斯、仪式巨像、祭礼巨像、獠牙猪、海豹船长、寒音蛇、烈火守护、波多西及尚未确认的例外不自动填入。

机幕方舟的既有目标侧25%覆盖仍仅在相关目标情形生效，不叠加为30%+25%；离开后恢复攻击方应有的默认或手工值。普通目标不再无条件清空百分比。详细ID与特性来源审阅见 `trait-power-defaults.md`。
