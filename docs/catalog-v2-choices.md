### 不再用父链反推整个家族

| 字段 | 含义 |
| --- | --- |
| evolution_members | 当前精灵自己的官方evo成员列表；源ID准确映射成本地ID，保持源顺序，不做对称或传递补全 |
| evolves_from_id | 明确的普通直接前置；必须在当前成员列表中，不从数组顺序猜箭头 |
| leader_of_id | 独立首领化来源，不再混入普通进化前置 |
| main_form_id | 原有同名主形态／变体关系，不承担跨名称首领化 |

这是一份平面邻接资料，而不是嵌套树。成员列表与直接关系分开，避免一个错误父节点把整族分组带偏。v1只在读取迁移时生成一次旧成员快照供比较；v2正常运行不再按父链重建家族。旧程序不能读取v2时会明确拒绝降级，不应混用旧EXE。

## 更新页面现在怎么用

1. 关闭旧检查版，打开[新检查版程序](<D:/echoagent/MeowNyx Wiki/dist/app/小黑猫 Wiki.exe>)。不要只复制EXE，需保留旁边资源目录。
2. 进入数据更新，检查官方更新。
3. 差异表每行有互斥的**本地／源**单选框，也可批量选择所有页的可用源或本地。
4. 点击**保存选择并应用**，确认后提交。未选的新项目保持本地，但不记忆；以后仍可再选择。
5. 完成后重新载入资料。

- 选择本地：以后保留本地，不再重复列为待选。
- 选择源：以后跟随有效源值，不重复要求选边，但仍需点击应用才落盘。
- 已记忆项可逐条或全部撤销。**撤销记忆不是撤销已经应用的数据**；它只解除以后采用哪一边的策略。
- 源缺失／非法显示不可选；不会把查询失败当空库。合法明确空成员数组可清除普通前置。无效引用、双重前置、循环及身份冲突仍会阻止错误组合，不擅自替你勾选依赖项。
- 不再长篇解释为什么不同；成员、前置、首领和技能都以中文名称＋准确ID展示，完整值可展开，未裁掉长学习面。
- 普通立绘只有一条独立策略：本地表示不下载；源表示安全校验后补缺或使用更大普通立绘。没有伪装成像素内容差异，也不放弃原头像／尺寸／格式保护。
