# 小黑猫 Wiki 1.3

## 主要更新

- 精灵身份按稳定ID解析，修复旧名称、形态与学习面关联；保留独立学习面和继承规则。
- 伤害计算与曲线共用基础算术，修复技能类型/威力同步、属性倍率和星陨取整；支持完整技能记忆及白/黑加尔固定威力表达式。
- 曲线收藏、分组、个体/性格独立；新增18属性自动预设，血脉风格图标菜单，可复制成普通组。保留等效生命、整数击杀阈值、缩放命中及最大化自适应。
- 个人配置迁入固定AppData共享文件，支持自动默认与人工配置；恢复默认和全部清空是两个不同的确认操作，更新软件不自动执行它们。
- 新增游戏描述表格与词条悬停说明；技能筛选支持右键排除；学习者表格支持属性置顶。
- 速度页临时勾选/加成/选择恢复为内存状态；头像优先顺序及形态仍保留。统一设置保存、失败重试和关闭时等待落盘。

## 发布文件

- `小黑猫Wiki-Setup-v1.3.exe`：Inno Setup安装包。
- `小黑猫Wiki-v1.3-Portable.zip`：Bandizip生成的ZIP便携包。

运行环境：Windows 10/11的64位兼容系统，以及Microsoft Edge WebView2 Runtime。安装包可在勾选对应任务且尚未安装运行时时下载WebView2，下载需要联网。便携版需自行确保运行时已安装。

便携版请完整解压，不能单独移动EXE：`js`、`css`、`data`、`assets`及`index.html`必须与程序相邻。便携的是程序文件；个人设置仍在同一Windows账户的 `%AppData%/小黑猫Wiki/`，不是随ZIP附带的个人档案。

## 升级与数据安全

- 两种包均不包含开发者的个人设置、浏览器存储、测试输出、备份或源码目录。
- 建议升级前正常退出程序。新版本保留兼容的程序文件名、安装AppId和个人数据目录。
- 新版本可一次性补入旧浏览器中的指定个人配置；不会用空记录覆盖已有共享记录。历史版本并不自动认识新共享配置文件。
- 主游戏资料随程序分发。若自行编辑过精灵/技能资料，应先自行备份这些资料再升级；个人配置和游戏主资料不是同一份文件。
- 本次发布准备不会运行安装包、卸载已有版本、清空真实个人配置或删除现有dist产物。

发布前运行Node测试、Go测试/vet、学习面审计和技能预设审计；生成GUI子系统程序。检查ZIP完整性并解压逐文件核对，核对安装包输入清单与同一套运行资源。
