# 曲线单线显示、生存标记与预设导入

> 本文记录上一批基础实现。后续已将曲线改为仅正性格、四按钮全开12种/其它仅1种、一次性默认重置、单线六步/多线仅⑥、Survivors100只上限及新增收藏预设。当前完整规则以 `twelve-curves-and-shortcuts.md` 为准，下面旧控件/悬停约定不再作为现行需求。

本批仅更新开发检查版；不覆盖旧安装或发布包，不改变主资料、伤害公式及曲线原有的计算效果范围。

## 四按钮与旧配置迁移

- 攻击方：当前物攻/魔攻个体，以及当前攻击性格；原来的左键正性格、右键负性格保留。
- 防守方：当前物防/魔防个体，以及生命正性格。**生命个体始终开启，没有开关。**
- 默认攻击个体、防御个体开启，攻击性格与生命性格不选；显式保存的攻击/防御选择继续保留。
- `controls.hpNature`为生命正性格正式字段。旧v1只有`doubleLife`时按原true/false迁入hpNature：旧true保留生命正性格，旧false保留中性生命性格，但生命个体现在总是开启。
- `doubleLife`继续镜像为兼容别名，只表示生命性格，不能再控制生命个体。两字段同时存在时hpNature优先。
- 迁移通过原有串行原子保存、失败提示及重试完成；保留组、成员和其他元数据。不读取伤害页个人个体/性格。
- 生命性格改变HP、等效生命、斩杀门槛，不改变技能伤害。图例明确显示当前“生命性格”状态，不再把固定中性的防御性格误显示为这个按钮。

## 默认单线与红绿框

当前按钮配置对应的伤害曲线默认显示，其余生成的对照线仍保留在图例中，默认隐藏。手动图例选择可以打开对照；改四按钮配置后重置为当前配置线，不重置到原始基准线。单纯主题、尺寸刷新保留图例选择。

图上和组内头像以当前可见伤害线判断：

- 恰好一条：精确实际伤害 >= 自身HP为红框，否则绿框。
- 没有伤害线或同时显示多条：中性边框。
- 参考虚线与头像散点不算伤害线。
- 单独显示某条对照线时，使用那条线的个体/性格配置，而不是仍用按钮配置。

每个精灵使用自己的默认等级、真实防御/HP和属性倍率。倍率进入单击最后一次floor之前，连击在之后乘。不能按图像位置、平滑插值或HP/倍率坐标断定斩杀。被挪开的头像通过引导线关联参考点，实际结果仍以完整公式为准。对照配置与按钮配置不同时，悬停分别标明。

## 两种曲线的当前判定点

- 伤害-防御模式：沿用当前攻击精灵、技能基础威力/固定加成/百分比/本系/BUFF/连击；仍不加入减伤、防御增幅、星陨或手动最终威力。
- 防御-伤害模式及换轴模式：按当前记忆的攻击资质和独立技能威力，以及本模式个体/性格/本系计算。初始资质120、威力200，切轴可分别编辑。头部标明当前判定点。
- 不是要求整个横轴范围内都无法斩杀，也不是把最低斩杀坐标处的伤害当作当前伤害。
- 最低整数攻击资质/技能威力的头像横坐标仍保留，按门槛左右两侧完整公式验证；悬停当前伤害按当前判定点显示。

## 动态“所有不可斩杀的精灵”

内置ID为`preset:Survivors`。候选范围与18属性预设一致：高级形态、主形态/无多形态、非隐藏、非首领，按稳定ID去重。

每次从当前按钮配置及当前攻击参数筛出`damage < HP`的精灵；这不是免死、锁血或复活特性名单，也不是所有对照线的并集/交集。数据与参数改变后重新派生，只保存选中的预设ID，不保存冻结成员。

上下文尚未具备时明确显示不可用，不把无法计算伪装成空名单。依赖单向为“预设 -> 当前配置求值器 -> 单只精灵伤害”，不回读当前分组/头像，避免递归。

18属性图标仍为3×6，新动态预设是其下独立文字按钮；键盘可选。内置预设只读，不加入普通“全部组”，仍可复制成独立的自建组。

## 将预设追加到自建组

管理自建组时选择预设并点击“导入预设”：

1. 取得该预设当时的成员快照。
2. 追加到当前自建组，按ID去重，保留已有成员和原顺序。
3. 不覆盖原列表、不改变当前组，不因未来预设变化自动移除成员。

重复导入只增加缺少的成员。“未分组”也可作为目标；“全部组”不是目标组。原“复制组”功能仍能另建可编辑副本。

失败时保留上次提交的状态，阻止叠加未提交修改；重试保存的是当时失败的快照，不重新读取已变化的动态名单。
