# 曲线 all 开关与预设按钮布局

本次为纯前端交互调整，不改Go或配置结构，不更新controlsRevision，不再次重置四按钮，也不重新编译EXE。

## 减伤快捷按钮

每个50/60/70/80/90按钮的上下内边距由9px改为8px（减少约11.1%）；左右仍5px，边框仍1px。菜单本身仍10px内边距，按钮间距仍6px。输入、计算、保存与失败重试不变。

## 两个预设按钮

18属性仍3×6，下面新增一行两等分布局：左“斩杀预设”，右“收藏预设”。较窄窗口与200%缩放下也保持左右排列。

正常入口显示这两个固定名称。斩杀预设超过100只时仍可点击，但点击只将该按钮文字临时改为“不可斩杀精灵过多”，约2秒后恢复；不切组、不改当前图、不写配置、不进入保存失败/重试状态。关闭菜单会取消计时，重新打开恢复名称；当前已低于上限时恢复正常。

恰好100只允许进入，0只为空结果；没有计算上下文、保存未完成等其它不可用状态仍有各自保护。底层上限和复制/导入检查不取消，不能绕过，不截取前100。已有自建组快照不变；已选择的动态组变成超限时仍暂停其结果。内部preset ID、收藏来源和去重规则不变。

## all 展示开关

- 不管四按钮是否全开，默认只生成当前一条曲线。
- 四按钮全开时，在生命性格右侧出现小写`all`按钮，初始未激活。
- 激活变为与其它激活按钮相同的绿色，生成12个配置选项；初始仅显示当前全开配置（攻击个体＋正性格、防御个体＋生命正性格），其余11条在图例中可见但曲线隐藏。
- 可从图例逐条显示或隐藏，包括隐藏当前全开配置、显示全部12条或隐藏全部。手动操作不关闭all；数字参数重算、主题/字体/尺寸更新不恢复隐藏线，也不隐藏手动显示的线。
- 再点all退出12配置模式，回到当前按钮对应的一条可见线，四按钮本身不变。再次激活all重新以当前线可见、其余11条隐藏开始，不沿用上一次已退出的all图例选择。
- 四按钮有任意项改变时退出all；不再满足全开时隐藏按钮。重新全开后仍需主动点all。
- all及图例选择只属于当前应用会话的展示状态，不写个人配置；同会话离页/返回、控件未改变时保留all及确切的显示/隐藏选择，重新启动默认关闭。原有模式、攻击类型、轴切换的展示签名重置规则不变。
- 不修改生命个体常开、攻击个体/正性格联动、单线六步/多线各⑥、红绿框的既有规则。参考线和散点不计入伤害曲线数量。

## 删除固定400参考线

伤害-防御模式不再生成固定400伤害参考数据集，也不再注册该阈值的交点标签。固定值、固定线名称、反向查找交点分支直接删除，不以隐藏、注释或不可达条件保留。防御模式只绘制伤害曲线及有效收藏头像。

攻击资质/技能威力两种扫描仍保留按当前目标真实HP计算的`斩杀线(HP)`及第一个达到HP的交点标签；HP个体恒开，HP性格取当前曲线控件。保持原有范围规则：所有生成曲线均未达到目标HP时不生成该参考线。真实HP线支持图例隐藏，但不参与可见伤害曲线计数。伤害公式、重合线数值、收藏头像及红绿框精算不变。
