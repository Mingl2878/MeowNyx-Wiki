# 小黑猫 Wiki

洛克王国精灵图鉴 & 伤害计算器 · 桌面版

## 简介

小黑猫 Wiki 是一个离线可用的洛克王国资料查询工具，基于 Go + WebView2 构建，无需安装数据库，解压即用。

## 功能

- **精灵图鉴** — 查看所有精灵的种族值、属性、特性、进化关系
- **技能列表** — 按名称/属性/类型/能耗/威力筛选技能，支持关键词搜索（如"永久""连击"）；威力单选精确值、双选区间，140+为开放上限
- **克制关系** — 查询任意属性的攻击/防守克制倍率，扇形色块网格 + 分类列表
- **速度速查** — 速度档位表，基础速度换算各种加成下的实际速度
- **组队系统** — 编排队伍，管理队伍成员与候选精灵
- **伤害计算** — 计算技能伤害，考虑属性克制、buff、被动效果
- **伤害曲线** — 防御/攻击资质与威力曲线，独立收藏分组、18属性自动预设
- **游戏描述** — 本地词条表格及技能、特性中的悬停释义
- **个人配置** — 本地共享保存、自动默认/人工选择，以及独立的恢复默认和全部清空操作
- **数据更新** — 纯 Go 检查腾讯图鉴，以随包的已确认源值为增量基线，已知旧差异不反复提示，后续新增／平衡变化继续更新。逐项选择本地／源，单次确认与长期策略分开；确认应用才提交。无需 Python 或 Node.js

当前主资料为 [catalog.json](<data/catalog.json>)（schema v2，兼容迁移v1），旧四份 JSON 只作内存兼容视图，不应再手工覆盖旧文件。mieli用于一次性全库校准，玩家后续仅从腾讯更新；明确普通进化、首领化和同名形态分开保存。详情右栏属性克制下方用紧凑文字箭头展示完整家族，分支使用斜箭头，当前形态文字高亮；无头像、边框和固定画布。当前校准结果作为出厂初始资料，长期记忆从0开始，腾讯增量基线保留。现行规则见 [客户端校准与腾讯增量基线](<docs/catalog-mieli-baseline.md>)，上一阶段记录见 [图鉴v2和选择记忆](<docs/catalog-v2-choices.md>)。

最新开发增量：进化关系整块左对齐；等级特性支持可配置范围、默认等级和步进，银月狼王进化链提供属性值／种族值／冥古龙／阿布四模式，见[等级说明](<docs/levels-and-trick-room.md>)。等级采用不可点击文字、滑块与相邻档位增减按钮。启动只读取本地资料并复用已验证的不可变图鉴投影，不自动在线检查；更新页提供详情弹窗、全选/反选/取消选择/记忆已选项及同排检查/应用/重新载入，见[交互说明](<docs/update-review-and-level-ui.md>)。本地三只方方系精灵的恢复测试只操作当前用户活动资料，不删改完整出厂图鉴。

最新筛选与展示：威力最多选两个端点，选满需先取消旧端点；140+单选≥140，与60同选≥60、无上限。兽花蕾与陨星虫去掉补充标题、效果逐条换行。进攻抵抗精灵按0.5/0.25互斥计数，复制去掉属性与倍率间冒号，详见[筛选与属性工具](<docs/skill-simulation-and-type-tools.md>)。仅展示/筛选变化，不修改精灵效果数值或玩家资料。

烈火战神吹火威力与BUFF共用累计次数：50对应0%，50+(1*20)对应30%，50+(2*20)对应60%。每次右键使次数＋1。双攻跨技能保留，切换精灵／重启后恢复，左键吹火清零两份累计但保留独立手工BUFF。仅此精灵＋技能组合触发，不扩展到其他火系技能；详见[技能模拟说明](<docs/skill-simulation-and-type-tools.md>)。精灵列表的地区形态／特性折叠三角也已调整到固定表头下方。

冥古龙已录入六项资质、等级特性效果及主龙／副幽双属性，特性名称/形态等未提供资料仍待补充。速度速查只保留`70 · Lv99`一行，右侧`< >`可在完整1/9/19/…/99档位切换并实时重算速度；伤害页受击方冥古龙低于80级自动填威力百分比40%，离开条件恢复原值，见[等级说明](<docs/levels-and-trick-room.md>)。

速度速查常驻去掉49/44/40，但搜索仍可临时补行；冥古龙单行固定在105与100之间。首领与对应高级形态同速时，优先显示两页搜索或伤害页快捷头像最近一次主动选中的那只（历史、收藏、编队的左键攻方/右键守方均有效）；历史栏顺序不变，仅无有效选择记录时才显示高级形态，不同速双方都显示。手动BUFF按输入值接管，空白/纯空格按手动0处理，吹火左右键均可用，不再因清累计而生成隐藏负补偿，详见[显示与BUFF规则](<docs/skill-simulation-and-type-tools.md>)。

普通精灵的快捷选择也已接入速度优先展示：在伤害页搜索或从历史/收藏/编队选中落陨星兔等精灵，使用同一份独立优先记录，快捷历史栏自身不挪位置。速度页当前搜索仍优先，首领显隐、筛选和数值规则不变。

新增超能阿布（单龙、首领，圣龙的守护），可用1费龙吼与3费龙炮；默认60级，60/62/…/98/99档位。自身及银月狼王/诅咒狼灵/新月狼灵的阿布模式，物攻成长按每级5%自动填增减益BUFF；受击低于80级时阿布填威力百分比30%、狼系冥古龙模式填40%。退出条件恢复原值，手工BUFF与原精灵资料保留，详见[等级与模式效果](<docs/levels-and-trick-room.md>)。

伤害曲线已接入攻击方卡片当前等级（含阿布/冥古龙及狼系模拟、战报临时等级）：物攻/魔攻换算与伤害系数同步变化，悬停①展示等级属性公式、⑤展示完整等级系数与逐击取整。曲线个体/性格、防守收藏默认等级和原有效果范围保持独立。

1.3发布文件分别为 `小黑猫Wiki-Setup-v1.3.exe` 和 `小黑猫Wiki-v1.3-Portable.zip`；更新内容及升级注意事项见 [1.3说明](docs/release-v1.3.md)。

## 系统要求

- Windows 10 / 11，64位兼容系统
- Microsoft Edge WebView2 Runtime

## 编译

```bash
# 使用 go.mod 指定的 Go 工具链版本
go build -ldflags "-H=windowsgui" -o "小黑猫 Wiki.exe" .
```

## 目录结构

```
├── main.go          # Go 后端（静态文件服务 + 数据编辑 API）
├── index.html       # 前端入口
├── rsrc.syso        # Windows 图标资源
├── data/            # catalog.json 规范化图鉴 + 游戏机制词条
├── assets/          # 图片资源
│   ├── icons/       # 图标（UI/属性/技能/魔法道具）
│   └── monster/     # 精灵图片/技能图/特性图
├── css/             # 样式
└── js/              # 前端逻辑
    └── pages/       # 各页面模块
```
