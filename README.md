# 小黑猫 Wiki

洛克王国精灵图鉴 & 伤害计算器 · 桌面版

## 简介

小黑猫 Wiki 是一个离线可用的洛克王国资料查询工具，基于 Go + WebView2 构建，无需安装数据库，解压即用。

## 功能

- **精灵图鉴** — 查看所有精灵的种族值、属性、特性、进化关系
- **技能列表** — 按名称/属性/类型/能耗筛选技能，支持关键词搜索（如"永久""连击"）
- **克制关系** — 查询任意属性的攻击/防守克制倍率，扇形色块网格 + 分类列表
- **速度速查** — 速度档位表，基础速度换算各种加成下的实际速度
- **组队系统** — 编排队伍，管理队伍成员与候选精灵
- **伤害计算** — 计算技能伤害，考虑属性克制、buff、被动效果
- **伤害曲线** — 防御/攻击资质与威力曲线，独立收藏分组、18属性自动预设
- **游戏描述** — 本地词条表格及技能、特性中的悬停释义
- **个人配置** — 本地共享保存、自动默认/人工选择，以及独立的恢复默认和全部清空操作
- **数据更新** — 本地添加/编辑精灵、技能数据

1.3发布文件分别为 `小黑猫Wiki-Setup-v1.3.exe` 和 `小黑猫Wiki-v1.3-Portable.zip`；更新内容及升级注意事项见 [1.3说明](docs/release-v1.3.md)。

## 系统要求

- Windows 10 / 11，64位兼容系统
- Microsoft Edge WebView2 Runtime

## 编译

```bash
# 需要 Go 1.21+
go build -ldflags "-H=windowsgui" -o "小黑猫 Wiki.exe" .
```

## 目录结构

```
├── main.go          # Go 后端（静态文件服务 + 数据编辑 API）
├── index.html       # 前端入口
├── rsrc.syso        # Windows 图标资源
├── data/            # JSON 数据（精灵/技能/属性克制/wiki）
├── assets/          # 图片资源
│   ├── icons/       # 图标（UI/属性/技能/魔法道具）
│   └── monster/     # 精灵图片/技能图/特性图
├── css/             # 样式
└── js/              # 前端逻辑
    └── pages/       # 各页面模块
```
